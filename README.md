# 🎓 Pós-Graduação em Arquitetura de Software — PUC Minas

Este repositório foi criado para centralizar, organizar e documentar toda a minha jornada de estudos, projetos práticos e anotações teóricas durante a especialização em **Arquitetura de Software** pela **PUC Minas** (Turma 2026).

O objetivo principal é aplicar os conceitos de padrões arquiteturais, escalabilidade, segurança e governança de sistemas na prática, construindo um portfólio técnico sólido.
